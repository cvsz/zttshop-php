# Code of Conduct

## Our Pledge

We expect contributors and maintainers to act professionally and respectfully.

## Expected Behavior

- Be clear and constructive
- Focus on the code and the issue
- Respect other participants' time and work

## Unacceptable Behavior

- Harassment
- Personal attacks
- Discriminatory language
- Deliberate disruption of discussion or review

## Enforcement

Project maintainers may remove comments, close issues, or reject contributions that violate this code of conduct.

## Reporting

Report conduct concerns through the issue tracker or project contact path documented in `SUPPORT.md`.
