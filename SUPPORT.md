# Support

## Getting Help

For usage questions:

- read `README.md`
- read `PROJECT_DOCS.md`
- review the PHPUnit tests in `tests/`

## Best Place To Report Issues

- GitHub issues for bugs and feature requests
- Pull requests for fixes

## Before Opening an Issue

Include:

- the resource class involved
- the API path being called
- the PHP version
- the composer dependencies in use
- the exact error response if available

## Known Limitations

- Some tests require live TikTok Shop credentials
- The package is resource-oriented and does not currently expose a single top-level facade class
